## 📌 Project Overview

This repository contains end-to-end data mining implementations designed to solve two core real-world problems:
1. **Network Fault Detection:** Classifying node health status based on network telemetry parameters.
2. **Market Basket Analysis:** Discovering customer purchasing patterns to generate real-time product cross-sell recommendations.
